
RF-01: El sistema permitirá crear, consultar, editar y eliminar Piezas
RF-02: El sistema permitirá crear, consultar, editar y eliminar Gastos
RF-03: El sistema permitirá crear, consultar, editar y eliminar Categorías
RF-04: El sistema permitirá crear, consultar, editar y eliminar Estilos
RF-05: El sistema permitirá crear, consultar, editar y eliminar Estados
RF-06: El sistema permitirá crear, consultar, editar y eliminar Métodos de venta
RF-07: El sistema permitirá crear, consultar, editar y eliminar Materiales

RF-08: El sistema permitirá que en usuario busque filtre, organice y ordene sus Piezas en base a sus diferentes atributos.
- Nombre (alfabéticamente)
- Estado
- Categoría/s
- Estilo/s
- Material/es
- Método de venta
- Precios (ordenar mayor/menor)
- Fechas (ordenar antes/después)

RF-09: El sistema permitirá que en usuario cambie entre distintos métodos de visualización de Piezas. Opciones de imagen grande, imagen pequeña y sin imagen.

RF-10: A la hora de buscar requisitos mediante la barra de búsqueda se priorizará que coincida el nombre de la pieza, pero también se buscarán coincidencias en el texto de Estilo, Categoría, descripción, etc.
